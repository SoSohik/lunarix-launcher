============================================================
              LUNARIX LAUNCHER (FABRIC 1.21.11)
============================================================

Оновлена версія лаунчера з новим дизайном, інтеграцією Modrinth
та повною автоматизацією.

ОСНОВНІ ОСОБЛИВОСТІ:
  1. Стильний темно-синій дизайн (Cyber Blue / Sapphire) з іконкою софта Lunarix.
  2. Повна автоматизація в 1 клік:
     - Лаунчер сам перевіряє стан гри.
     - Якщо гру ще не завантажено — з'являється велика кнопка "ЗАВАНТАЖИТИ КЛІЄНТ",
       яка завантажує Minecraft 1.21.11, Fabric, Lunarix, Fabric API та Sodium.
     - Як тільки клієнт готовий — кнопка перемикається на "ГРАТИ" для миттєвого запуску!
  3. Вкладка "Моди" (розблоковується після завантаження клієнта):
     - Встановлені моди: список усіх модів у папці mods/.
     - Каталог Modrinth: вбудований магазин модів для Fabric 1.21.11. Можна знайти
       будь-який мод (Sodium Extra, Iris, Lithium, AppleSkin тощо) та встановити
       його в один клік прямо в папку mods/!
  4. Жодних складних налаштувань для звичайного користувача:
     - Приховані зайві токени: користувачу достатньо просто ввести нік і натиснути "ГРАТИ".
  5. Перетворення в .EXE:
     - Запустіть файл "build_exe.bat" — лаунчер автоматично скомпілюється в один файл
       "Lunarix Launcher.exe", який можна передавати друзям без встановлення Python!

ЯК ЗАПУСТИТИ ЗАРАЗ:
  - Двічі клікніть "Запустити Лаунчер.bat"!
============================================================
